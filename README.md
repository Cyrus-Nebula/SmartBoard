# 智学白板 SmartBoard

基于 **PySide6** 的多功能教学白板（智学白板）。支持手写笔迹平滑、橡皮擦、
撤销/重做、清空、白板文件保存与载入。

## 兼容目标

- Python 3.7+
- PySide6 6.2.4+

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 功能

- **平滑书写**：采用「中点 + 二次贝塞尔」算法对手写采样点做平滑，笔迹自然圆滑。
- **自然笔（速度感知变宽）**：工具栏「自然笔」开关（默认关闭）开启后，笔迹随书写速度变化粗细——慢笔粗、快笔细，模拟真实钢笔 / 毛笔手感，板书更有节奏与层次。实现上按采样点时间戳估算逐点书写速度，映射到半宽后用「中心线偏移成闭合轮廓 + 填充」渲染（现代变宽描边的标准做法）；提交时同步对「点—时间戳」做 RDP 抽稀，保证存储精简。该特性**默认关闭**，因此不改动任何既有默认书写行为，老白板文件（无半宽数据）载入后仍是原来的固定宽度笔迹，对橡皮擦、序列化与导出管线零侵入。
- **缩放感知采样**：鼠标采样的“最小间距阈值”随画布缩放自适应，始终保持「屏幕约 1px」恒定。放大讲解细节时不再因采样点被丢弃而让笔迹变锯齿；缩小总览时也不会过度密集采样。缩放/平移只作用于视图变换，同样对场景数据与导出管线零侵入。
- **笔迹自动抽稀**：提交笔迹时用 Ramer–Douglas–Peucker 算法按 1.5px 容差抽掉冗余近共线采样点，白板文件体积与载入/渲染开销显著下降（典型连笔可减少 6–7× 点数、约 85% 体积），视觉几乎无差别。
- **调色板与线宽**：6 色调色板 + 1–40px 可调线宽。
- **橡皮擦 / 精确擦除**：橡皮擦以背景色覆盖方式擦除（像素橡皮），并按「绘制顺序」层叠——只遮住它之前的笔迹，不会压住之后新画的笔迹。此外，**右键点击任意笔迹可整条删除**（对象级擦除），误删可用 Ctrl+Shift+Z / Ctrl+Y 恢复，非常适合课堂即时纠错。
- **荧光笔（高亮笔）**：工具栏「荧光笔」开关（默认关闭）开启后，笔迹以半透明（约 40% 不透明度）叠加渲染，可叠在既有板书上突出关键结论、公式或重点词句，而不会遮挡其下的文字——像真实马克笔一样高亮而不覆盖。荧光笔与橡皮擦互斥（同一时刻只能处于「画笔 / 橡皮擦 / 荧光笔」之一）；选色只改变高亮色、不会退出荧光笔模式。该特性**默认关闭**，因此不改动任何既有默认书写行为，老白板文件（无 `highlighter` 字段）载入后仍是原来的不透明笔迹，对橡皮擦、序列化与导出图片管线零侵入。
- **撤销 / 重做 / 清空**：完整的笔迹编辑栈，工具栏按钮随场景状态自动启用/禁用。**「清空」（Ctrl+L）现已可一键撤销（Ctrl+Z）**——课堂误按清空不再永久抹掉板书，Ctrl+Z 整批还原；恢复后保留各笔迹层叠顺序，可继续在其之上书写。
- **保存 / 载入 / 导出图片**：白板以 JSON 格式序列化，便于分发与二次处理；并可将当前白板**导出为 PNG 图片**（工具栏「导出图片」按钮），仅截取笔迹内容区域（含留白），所见即所得，方便课堂分享与留存。
- **载入原子性保护**：载入白板文件时先完整解析并校验全部笔迹，**全部通过后才替换场景内容**。若文件损坏或任一笔迹格式非法，整体载入失败并给出明确提示，且**不会清空正在编辑的当前白板**——杜绝「误载损坏文件导致课堂板书被抹掉且无法撤销恢复」的数据丢失风险（载入前请记得先 `Ctrl+S` 备份）。
- **画笔状态可视化**：当前激活颜色高亮，橡皮擦激活时颜色按钮自动降亮。
- **画笔尺寸预览环（随缩放同步）**：视口上叠加一个与当前画笔在**屏幕上实际宽度（线宽 × 缩放）**等大的透明圆环，实时跟随鼠标，下笔前的落点与笔宽一目了然（尤其适合投影授课）；橡皮擦模式自动隐藏。该环挂在视口上而非场景图元，因此**不会被卷入「导出图片」**，对既有书写与导出管线零侵入。**环直径会随画布缩放同步变化**（放大后环变粗、缩小后变细），始终真实反映落笔粗细，避免缩放后“环比实际笔迹细/粗”的误导。
- **实时状态栏**：底部状态栏常驻展示「工具（画笔/橡皮擦）/ 颜色 / 线宽 / 笔迹条数 / 可撤销·可重做」，书写状态一目了然，尤其适合投影授课或远离屏幕的场景。
- **画布缩放与平移**：滚轮以光标为锚平滑缩放（教学时放大细节 / 缩小总览），中键拖拽平移漫游大图，工具栏「重置视图」或 `Ctrl+0` 一键复位。缩放/平移只作用于视图变换，不改动笔迹、预览环与导出图片，对既有书写、橡皮擦与导出管线零侵入。
- **适应内容（一键总览）**：工具栏「适应内容」或 `Ctrl+F` 可一键把当前所有笔迹缩放并平移到刚好铺满视口，便于快速总览整块板书、投影讲解时迅速回到全貌。空白板自动退化为复位（缩放归 1、原点居中）。该操作**仅作用于视图变换**，对笔迹、橡皮擦、序列化与导出图片零侵入。
- **状态栏实时缩放百分比**：底部状态栏在原有「工具 / 颜色 / 线宽 / 笔迹数 / 可撤销·可重做」基础上新增「缩放 N%」实时读数，随滚轮缩放、适应内容与复位即时联动，投影/远端授课时一眼看清当前视图比例。
- **AI 教学联动**：工具栏「AI 答疑」可将当前白板内容作为上下文向 AI 提问；默认本地规则答疑（无需联网即可演示）。已配置 `SMARTBOARD_AI_ENDPOINT`（及可选的 `SMARTBOARD_AI_KEY`）时，会经**标准库 `urllib` 真正发起一次 HTTP 请求**接入远程大模型——无需 `requests` 等第三方依赖，兼容 Python 3.7；请求带 8s 超时，响应兼容「纯文本 / `{"answer": ...}` / OpenAI 风格 `{"choices":[...]}`」三种格式；**任何网络异常、超时或畸形响应都会优雅降级到本地答疑**，绝不抛异常中断白板使用（密钥经 Bearer 头注入，不写死、不改动界面代码）。
  - **板面感知答疑（新增）**：本地答疑不再只是笼统提示，而是基于白板结构化统计（`analyze_board`）给出有针对性的教学建议——如实汇报「共 N 条内容（笔迹 M 条，含 K 处橡皮修正）、主要配色」，并据此提示「按步骤讲解 / 用不同颜色高亮关键结论」等；空白白板会额外提示先书写再提问。统计纯标准库实现、无 GUI 依赖，兼容 Python 3.7，便于单元覆盖。
  - **远程请求携带 stats 上下文（新增）**：调用远程后端时，请求体在原有 `question` / `context` 之外附带 `stats`（笔迹数、橡皮次数、配色分布等结构化摘要），让真实大模型更快把握板面规模与配色，无需逐行解析采样点文本；`context` 文本仍保留以兼容既有后端。
  - **板面感知「教学建议」（新增）**：`analyze_board` 在原有统计外新增量化指标——`ink_length`（板书采样点折线总长，量化「写了多少」）、`bbox`（非橡皮笔迹的版面包围盒，反映布局）、`highlighted`（荧光笔使用条数）；本地答疑据此给出**可执行的下一步动作**而非泛泛而谈：板书量偏少时提示补充步骤/图示、已有内容却未用荧光笔时建议高亮突出重点、已用高亮时引导聚焦、含橡皮修正时顺势讲解易错点、多色分层时给予肯定。统计纯标准库实现、无 GUI 依赖，兼容 Python 3.7，便于单元覆盖。
- **书写辅助网格**：工具栏「网格」按钮（或快捷键 `G`）可叠加一层极淡的参考线，帮助教师保持书写水平、对齐图形与公式，尤其适合投影授课。网格画在场景背景层，因此视图与 PNG 导出均「所见即所得」地包含它；**默认关闭**，对既有书写、橡皮擦、序列化与导出管线零侵入。
- **键盘快捷键**：为常用操作提供快捷键，书写过程中无需切换鼠标即可撤销/重做/清空/切换橡皮擦（见下方列表）。

## 键盘快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 重做 |
| `Ctrl+L` | 清空白板 |
| `E` | 切换橡皮擦 |
| `Ctrl+S` | 保存白板（JSON） |
| `Ctrl+O` | 载入白板（JSON） |
| 右键点击笔迹 | 删除该条笔迹（可重做恢复） |
| `Ctrl+加号` / `Ctrl+减号` | 放大 / 缩小画布（滚轮亦可缩放，中键拖拽平移） |
| `Ctrl+0` | 复位视图（缩放归 1、原点居中） |
| `Ctrl+F` | 适应内容（一键总览整块板书） |
| `G` | 开关书写辅助网格 |
| `H` | 开关荧光笔（半透明高亮笔） |

快捷键仅使用 Qt 6.2.4 已具备的 `QShortcut` / `QKeySequence` 公共 API，
挂载于主窗口（WindowShortcut 上下文），不影响工具栏按钮与鼠标书写流程。

## 项目结构

```
main.py                  启动入口
smartboard/
  app.py                 应用入口（QApplication + MainWindow）
  main_window.py         主窗口与工具栏（状态联动 + AI 答疑入口）
  view.py                白板视图（鼠标交互 + 实时预览 + 图片导出 + 自然笔速度采样）
  whiteboard.py          核心：Stroke 数据模型、WhiteboardScene、路径平滑、速度感知变宽
  ai_link.py             AI 教学联动（可插拔：本地答疑 / 真实可用的远程后端，标准库 urllib + 优雅降级）
tests/test_smoke.py      headless 测试套件（79 项，含缩放/平移/状态栏/缩放百分比/适应内容/缩放感知书写/网格/载入原子性保护/清空可撤销）
tests/test_ai_link.py    AI 联动单元测试（28 项：含板面感知统计 analyze_board 的量化指标 ink_length/bbox/highlighted、本地答疑增强与板面感知教学建议、远程后端真实调用的 monkeypatch 与降级验证）
tests/test_natural_pen.py 自然笔（速度感知变宽）单元测试（16 项：速度→半宽映射单调性/取值区间、变宽轮廓构造、序列化兼容、_attach 渲染分支、PNG 导出、工具栏开关与状态栏联动）
tests/test_highlighter.py 荧光笔（高亮笔）单元测试（17 项：序列化往返/老文件兼容、_attach 半透明渲染与颜色保留、自然笔+荧光笔组合、视图工具互斥/预览透明度/光标环隐藏、主窗口工具栏/状态栏/快捷键 H 联动、端到端提交）
```
